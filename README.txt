NOE'S SHOP - UPLOAD PACKAGE

1. Extract this zip on your computer.
2. Open the folder "upload-to-htdocs".
3. Upload EVERYTHING inside it into the "htdocs" folder on InfinityFree
   (use FileZilla / FTP; the File Manager cannot unzip files).
   Do not upload the zip itself, and do not upload the "upload-to-htdocs" folder;
   upload what is inside it, so that htdocs contains:

       .htaccess   app   public   vendor   writable

4. Delete InfinityFree's placeholder page in htdocs (index2.html or index.html).
5. Open your site address. No settings need to be edited.

The file ".htaccess" starts with a dot, so your computer may hide it.
In FileZilla: Server menu > Force showing hidden files. It must be uploaded.
